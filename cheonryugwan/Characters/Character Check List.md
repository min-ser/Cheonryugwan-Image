# 천류관 캐릭터 이미지 전체 체크리스트

> 천류관 게임 캐릭터 이미지 제작 현황 및 향후 제작 계획을 관리하기 위한 마스터 체크리스트.
>
> 캐릭터 이미지를 새로 생성하거나 기존 이미지를 보강할 경우 반드시 본 문서의 상태를 함께 갱신한다.

---

# 0. 체크리스트 관리 규칙

## 상태 표시

* `[x]` : 생성 완료
* `[△]` : 기본 디자인은 존재하지만 추가 이미지 필요
* `[ ]` : 미생성
* `[R]` : 기존 이미지 재생성 또는 수정 필요
* `[H]` : 보류 / 시나리오 확정 후 제작

## 캐릭터 이미지 공통 제작 기준

게임에서 실제 사용되는 캐릭터 이미지는 가능한 한 다음 기준을 통일한다.

* 전신 캐릭터 이미지
* 게임용 스탠딩 일러스트
* 캐릭터별 신체 비율 고정
* 얼굴 디자인 일관성 유지
* 머리색 / 눈색 / 헤어스타일 유지
* 세력별 복장 디자인 규칙 유지
* 무기 디자인 일관성 유지
* 손가락 기형 금지
* 손목 / 팔꿈치 / 어깨 관절 오류 금지
* 다리 비율 오류 금지
* 무기가 프레임 밖에서 잘리지 않도록 구성
* 검 / 도 / 단검 등의 손잡이가 휘어지지 않도록 구성
* 무기 끝부분까지 완전히 표현
* 불필요하게 복잡한 천 조각이나 끈 장식 최소화
* 찢어진 천 표현은 특별한 전투 장면이 아니라면 사용하지 않음
* 기본 스탠드는 깔끔한 복장 상태 유지
* 배경은 투명
* 흰색 배경을 투명 배경으로 간주하지 않음
* 캐릭터 주변 흰색 테두리 및 투명화 잔여물 제거
* 게임 UI에서 사용할 수 있도록 캐릭터 중심 정렬
* 동일 캐릭터의 표정 이미지에서 얼굴 구조 유지
* 특별한 요청이 없는 한 이미지 내부에 이름이나 글씨 삽입 금지

# 29. 체크리스트 갱신 규칙

앞으로 캐릭터 이미지 생성이 완료될 때마다:

1. 해당 캐릭터 항목을 `[ ]`에서 `[x]`로 변경한다.
2. 기본 디자인만 생성되었으면 `[△]`로 변경한다.
3. 표정 / 전투 / 이벤트 이미지까지 완성되면 `[x]`로 변경한다.
4. 수정이 필요한 기존 이미지는 `[R]`로 변경한다.
5. 시나리오 미확정 캐릭터는 `[H]`로 유지한다.
6. 생성 완료 수를 갱신한다.
7. 다음 생성 캐릭터를 지정한다.
8. 동일 캐릭터의 얼굴 / 복장 / 무기 설정을 이후 생성에서도 유지한다.

# 30. 최종 목표

천류관 캐릭터 이미지 제작의 최종 목표는 단순히 등장인물마다 스탠드 이미지 한 장을 만드는 것이 아니다.

각 캐릭터가 게임 시나리오에서 실제로 등장했을 때:

* 대화
* 감정 변화
* 전투
* 부상
* 과거 회상
* PTSD
* 세력 간 대립
* 주요 사건
* 엔딩

을 별도의 게임 이미지로 자연스럽게 표현할 수 있는 수준까지 캐릭터 자산을 구축하는 것을 목표로 한다.

특히 전서율 1권은 시간대와 정신 상태 변화가 이야기 자체의 핵심이므로, 전서율의 캐릭터 이미지는 하나의 디자인을 반복 사용하는 방식이 아니라 **시대별 / 상태별 캐릭터 세트**로 구축한다.
